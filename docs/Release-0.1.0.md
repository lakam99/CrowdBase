# CrowdBase 0.1.0

Continuous procedural crowd ambience for Windows x64, as a VST3 instrument and standalone app.

- Granular resynthesis of original synthesized crowd ensembles, with no announcers or film audio.
- Automatable energy, population, bed, cheers, applause, whistles and spatial controls.
- Big Play reaction with adjustable settling time; also triggered by MIDI note 36.
- Transport following, smooth automation, saved settings and per-instance seeds.
- Three analog raster finishes, cyan VFD values, hardware controls and an app icon.
- Rounded palm claps with reduced high-frequency hiss and sparse mellow activity.

Download **CrowdBase-0.1.0-Windows-x64.zip**, extract it and run **Install-CrowdBase.cmd**.
Then restart or rescan your DAW's instrument list. The package also contains the standalone,
full corresponding source, a 60-second audio example and verification reports.

Built and tested in GitHub Actions: DSP at 44.1/48/96 kHz, actual VST3 loading,
automation, play/stop behavior, session recall, editor open/close and repeated instance removal.
Checksums are supplied in SHA256SUMS.txt. No macOS binary in this release.
